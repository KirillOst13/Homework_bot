# 📚 Homework Bot

Телеграм-бот для учёта домашних заданий. Помогает не забывать про дедлайны и отслеживать прогресс.

![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python)
![aiogram](https://img.shields.io/badge/aiogram-3.x-green)
![License](https://img.shields.io/badge/license-MIT-orange)

## ✨ Возможности

- 📝 **Умное добавление ДЗ** — пиши в одну строку, бот сам всё поймёт
- 📅 **Автоматический парсинг дат** — поддерживает форматы `ДД.ММ`, `ДД.ММ.ГГГГ`
- 🎨 **Индикаторы срочности** — 🔴🟠🟡🟢 сразу видно, что горит
- ✏️ **Редактирование** — можно изменить предмет, задание или дату
- 📱 **Удобное меню** — кнопки внизу экрана, не нужно помнить команды
- 💾 **Асинхронная работа с БД** — быстро и надёжно

## 🚀 Быстрый старт

### 1. Клонируй репозиторий
```bash
git clone https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/homework_bot.git
cd homework_bot
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Получи токен бота
Открой [@BotFather](https://t.me/BotFather) в Telegram и создай нового бота командой `/newbot`. Скопируй токен.

### 4. Настрой конфигурацию
Открой `config.py` и вставь свой токен:
```python
BOT_TOKEN = "ТВОЙ_ТОКЕН_ЗДЕСЬ"
```

### 5. Запусти бота
```bash
python bot.py
```

## 📖 Примеры использования

### Добавить ДЗ
```
Математика: №123-125, до 08.10
Введение в ИИ: Выполнить практические 1-4, до 09.10
Физика: Глава 5, задачи 1-10, до 15.10.2026
```

### Посмотреть список
Нажми кнопку **«📋 Мои ДЗ»** или напиши `/homework`

### Редактировать ДЗ
Нажми **«✏️ Изменить»** под нужным заданием

## 🛠 Технологии

- **Python 3.10+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram
- **SQLAlchemy 2.0** — ORM для работы с БД
- **SQLite** — база данных (легко переключается на PostgreSQL)
- **python-dateutil** — умный парсинг дат
